# README screenshots

Captured from the macOS Apple Silicon package in
[v2.0.0-rc.2](https://github.com/zibo-chen/SubnetDesk/releases/tag/v2.0.0-rc.2),
using an isolated portable profile on 2026-11-06. These are running application
screenshots, separate from the concept images in `docs/design/`.

| File | View |
| --- | --- |
| `device-discovery.png` | Home, nearby devices, and local access controls |
| `local-device.png` | This device, connection address, and setup requirements |
| `lan-settings.png` | LAN access settings, with credentials left empty |

Images retain the actual device and permission states shown during capture.
Only the 56-pixel native title bar was cropped; content was not retouched.
Each image is 1920 × 1168 pixels and displays at up to 960 pixels in the READMEs.

To refresh, capture the same views from a current build without exposing
passwords or keys, keep the filenames, and update both READMEs together.
The README logo reuses the application's `res/subnetdesk-mark.png`.
