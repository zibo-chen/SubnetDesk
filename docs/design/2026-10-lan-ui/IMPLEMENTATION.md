## 本轮已落地

- 共用瓷白／茄紫／丁香色主题、表单、弹窗、菜单、按钮与状态样式，保留平台字体回退及深色主题。
- 新 Logo 与设备插画接入应用。图标导出脚本从同一透明 PNG 生成 Android、iOS、macOS、Windows、Linux 所用的 51 项资源。SVG 包装文件嵌入该 PNG；当前不是可编辑的矢量母版。
- 桌面首页改用顶部导航与居中连接入口；移动首页使用相同的信息结构及底部导航。设备列表、搜索、收藏分组、设备详情、完整指纹查看与复制、地址连接、最近连接使用真实数据和原有连接流程。
- 会话中心显示真实桌面会话窗口，继续操作聚焦对应窗口。远控、文件、终端、摄像头和端口转发窗口可返回标签对象信息供会话中心展示。
- 设置改为顶部分类、分段主题选择和响应式设置行，将外观、连接偏好、安全与出站凭据分开；本机共享的高级设置从“本机”进入。认证、信任核对及凭据存储沿用既有实现。
- 桌面详情将连接、文件传输和更多功能集中在设备信息下方；移动详情保留底部连接入口。附近列表及搜索列表按名称和地址稳定排序，可达状态更新不再使设备行换位；没有历史时的推荐设备也不随状态刷新跳动。
- 远控窗口保留原有画布及薄标签栏；悬浮工具栏采用统一样式，未固定时空闲约 2 秒收起，把手悬停约 150 毫秒唤出。鼠标位于工具栏、键盘焦点位于工具栏、菜单打开或拖动期间保持显示。

## 系统缩放

布局使用 Flutter 逻辑像素，不以物理屏幕像素决定尺寸。保留原生 `devicePixelRatio` 和系统 `TextScaler`，移除主入口强制文本缩放为 1 的处理。Logo 字标作为品牌锁定字保持固定字号，系统 DPI 仍正常生效。

工作区按可用逻辑宽度和文字大小调整导航换行、设备排列和内容滚动。详情保留连接入口；移动详情隐藏首页导航，键盘出现时让出底部导航空间。系统 UI 缩放不修改远程桌面的会话缩放和坐标映射。

Windows runner 已具备 PerMonitorV2 声明及 `WM_DPICHANGED` 处理，本轮未替换该原生逻辑。跨不同 DPI 显示器移动窗口仍须 Windows 实机验证。

自动化布局组合：桌面 1024×768 与移动 360×800 逻辑像素，DPR 1／1.25／1.5／2，文字倍率 1／1.5／2，共 24 组；另测 844×390 移动横屏、大字体设置行与受控模式返回行为。24 组测试覆盖工作区首页、搜索列表、空状态及详情，不能替代所有旧业务工具页的缩放验收。

## 小窗口修正

默认主窗口改为 960×640 逻辑像素，普通主窗口最小尺寸为 640×480；已有有效尺寸偏好仍会恢复。首次打开及恢复窗口时，尺寸限制在当前屏幕工作区内，Windows 的原生工作区先按显示器 DPI 换算成逻辑像素。纯受控模式继续使用原有独立尺寸规则。

桌面工作区以 960×612 客户区为基准，窗口更小时按宽、高比例中的较小值统一缩小文字、图标、间距和点击区域；不会放大大窗口或改写系统文字倍率。640×480 窗口的客户区为 640×452，正常文字下仍保留插画和附近设备。桌面首页使用同一套布局，页头及内容统一限制在 1040 逻辑像素宽度，左右边距 32；品牌与工具区各占 200，使正常字号下的单行导航位于窗口中轴。插图、设备信息和主连接按钮沿同一中轴排列，“更多”右侧操作以对称的左侧占位平衡，不再使主按钮偏左。附近设备使用间距 16、圆角 16 的两列轻边框卡片，底边距 24。刷新位于“查看全部”旁，地址连接使用右上角加号。大字体时导航可下移，内容正常滚动；移动端保留原有导航和详情交互。

桌面附近设备、收藏及最近连接的设备行默认直接远程连接。每行和首页连接按钮旁的“更多”共用文件传输、终端、摄像头、收藏／取消收藏、复制地址和设备信息操作。设备信息以可滚动弹窗展示地址、平台、状态、指纹及收藏分组，不再从桌面设备行进入二级页面。

最新 65 项工作区回归通过，包括 640×452 和 960×612 客户区 × DPR 1／1.25／1.5／2 × 文字倍率 1／1.5／2，检查居中连接／更多可命中、刷新可滚动到达、菜单目标设备与工具回调、设备信息弹窗及关闭操作。中英文分别在 640×452、966×677 和 1440×900 检查页头单行、主按钮与插图中轴、页头与内容左右对齐。覆盖等比缩放、设备行直接连接、收藏、复制地址、底部间距和加号连接流程。设备地址展示省略默认端口 21118，保留自定义端口和 IPv6 方括号；真实连接 ID、搜索及复制地址仍使用原值。

最新原生预览位于 `target/ui-scaled-preview/SubnetDesk Scaled QA.app`，使用同目录 `userdata` 内的独立测试配置。`01-home-balance-before.png` 与 `02-home-balance-after.png` 为同一 1932×1410 实际像素／966×705 逻辑像素窗口的调整前后截图；已在同一输入中与原设计 D01 对照，检查字体、间距、颜色、素材和实际文案。原生主按钮中心从 x=913.5 修正为窗口中轴 x=965.5（物理像素）。已点验会话导航、更多菜单和加号弹窗后返回首页。640×480 的可用性由上述客户区测试验证。
