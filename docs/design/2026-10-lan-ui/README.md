# SubnetDesk 桌面与移动端 UI / UX 设计稿

交付日期：2026-10-20。共 **43 张独立页面图：桌面 25 张、移动 18 张**。延续已确认的首页与方案二 Logo，适配局域网设备发现、连接与日常远程操作。

打开 [index.html](index.html) 可离线浏览、筛选、搜索和放大原图。点击卡片进入单页查看器，左右方向键切换，Esc 返回；“原始尺寸”可检查细节。所有图片按原始比例展示。

这是供评审与后续实现使用的视觉和交互设计稿。截图中的设备、地址、文件、消息、日期均为示例；图片不是已运行的软件，也不是状态或性能测量结果。功能可用性按实际平台与连接能力决定。

## 已确定的方向

- 温暖瓷白底、深茄紫文字和主操作、浅丁香选中态，少量杏色区分设备。去掉常驻侧边导航，用顶部导航和完整的任务页面组织桌面端。
- 使用方案二 Logo：两个错位圆角窗口角，中间留出方形负空间。页面中的品牌和功能图标已按这个方向统一；生产矢量、字体与各平台应用图标资源仍需实现阶段精修与导出。
- 桌面主窗口只有“设备／会话／本机”三个一级入口；设置固定放在右上。移动端使用同名底部导航，“会话”使用重叠窗口、“本机”使用手机图标，设置作为独立入口。
- 远控、文件、终端等工具在独立会话窗口打开，窗口支持多个会话标签，支持拆分和合并。“新窗口”是窗口管理需求，不改变网络端口或协议。

## 主要使用路径

| 用户任务 | 建议路径 | 关键处理 |
| --- | --- | --- |
| 继续上次连接 | 首页 → 连接设备 → 已有会话窗口 | 已有相同会话时优先聚焦，避免误开重复连接 |
| 连接新设备 | 附近设备／手动地址 → 首次身份核对 → 认证 → 会话窗口 | 地址输入与凭据分开；已验证设备不反复要求初次确认 |
| 找到设备 | 全部设备 → 搜索名称或地址 → 详情 | 未检查与暂不可达分开，不能把未检查直接显示为离线 |
| 远程操作 | 会话标签 → 远程画面 → 悬浮工具栏 | 控制界面覆盖在画布上，不挤压画面 |
| 传输文件 | 设备详情／远控“文件” → 文件会话 | 桌面双文件面板；移动单列切换；队列独立持续 |
| 管理多会话 | 标签拖动／标签菜单 → 拆分、合并、移动 | 移动会话归属，不重新建立连接 |
| 允许他人接入 | 本机 → 访问设置 → 按需授权 | 主动连接其他设备不依赖本机接收权限 |
| 连接失败 | 失败页 → 重试／编辑地址／查看检查建议 | 保留已填内容；明确已知错误，不把检查建议当检测结论 |

## 远程窗口：画面优先

对应 D11、D25、M10、M11。桌面窗口仅保留约 36–40 逻辑像素的标题／标签栏，画布铺满其余可用区域；不再放主窗口导航、常驻页脚或侧栏。显示比例默认适应窗口，支持原始比例和平移，不能拉伸远端画面。

悬浮工具栏采用“拖动把手／显示／输入／文件／画质／更多／固定或自动隐藏／结束会话”。显示和输入子菜单收纳低频选项；聊天、摄像头等从“更多”进入。通过远控打开文件或终端时，创建相应工具标签，远程连接继续保持。

### 自动隐藏规则（实现建议，需交互验证）

| 情况 | 行为 |
| --- | --- |
| 首次进入会话 | 短暂展开，说明唤出位置；之后进入自动隐藏 |
| 鼠标离开工具栏、菜单关闭且约 2 秒无本地工具栏操作 | 隐藏整条工具栏，仅留边缘小把手；远程输入继续正常转发 |
| 悬停把手约 150 毫秒／点击把手／使用可配置的唤出快捷键 | 以覆盖方式展开，不改变远端分辨率或窗口内容尺寸 |
| 展开菜单、键盘焦点停留在工具栏、拖动工具栏 | 暂停隐藏；不能在用户选择选项时突然消失 |
| 固定工具栏 | 保持展开，固定状态按会话窗口保存；允许随时解除 |
| 全屏 | 标签栏可一同自动隐藏；边缘把手保留，展开后可切换标签和退出全屏 |
| 隐藏时发生重连或需要用户处理的错误 | 显示小型状态反馈，并提供恢复或结束入口，不弹出大块装饰面板 |

把手和悬浮控件捕获的是本地操作，不能把触碰继续发送给远端。桌面把手可沿安全边缘移动；手机横屏默认靠侧边，避开系统手势区域。视觉可小，触碰区域需至少 48 × 48 逻辑像素。给快捷键提供冲突检查与修改入口，不能依赖快捷键作为唯一唤出方式。

移动端默认提供触控板／直接触控两种输入方式、键盘和更多菜单。键盘出现时画布可视区与光标位置需要适配；收起键盘后恢复可用空间。移动端多会话通过会话页切换，不强塞桌面标签栏；D23/D24 的窗口拆合适用于桌面。

## 一个窗口多个会话，支持拆分与合并

对应 D10–D13、D19–D21、D23、D24。标签以“功能图标＋设备名＋关闭”构成，类型通过远控／文件／终端图标区分，长名称截断并提供完整提示。可混放不同类型的工具标签。

- 新建工具默认进入当前会话窗口；有“在新窗口打开”的可见菜单选项。主窗口“会话”里的继续操作聚焦对应窗口与标签。
- 拖出标签栏时显示新窗口预览，松开后拆分；拖入其他窗口标签栏时显示插入位置，松开后合并。拖动取消或目标无效时恢复原归属。
- 连接对象、终端缓冲、文件队列、远程缩放与输入模式属于会话，移动标签时保留。实现不能把拖动处理成断开再连接。
- 标签菜单提供“移到新窗口／移到其他窗口”作为拖动的替代操作。左右移动标签、切换标签可通过键盘完成；快捷键在远控输入捕获状态下需要明确区分本地和远端。
- 关闭正在连接的标签意味着结束该会话，需要在有传输、运行中任务或其他不可恢复工作时说明影响。普通标签切换、返回主窗口不结束连接。
- 关闭多标签窗口前汇总将结束的会话；保留“取消”与“移到其他窗口”的路径。关闭最后一个标签后关闭空窗口，其他会话窗口继续。退出整个应用时单独说明所有活跃会话与传输的影响。
- 移动端返回操作将会话留在会话中心；显式“结束／停止”才关闭对应任务。后台持续能力服从系统限制，不能把图中的状态承诺为跨平台永久后台运行。

## 局域网发现、身份与认证

地址行展示名称、平台和可用地址，支持 IP 或主机名以及可选端口。附近设备来源、收藏分组、已保存身份是不同信息，不用一个绿色圆点混在一起。状态用图标和文字共同表达。

首次连接展示完整设备指纹，并引导与远端设备核对；确认框默认不选。身份变化时停止连接，显示旧／新值，提供重新核对路径，不直接给出普通“忽略继续”。现有 `libs/hbb_common/src/lan.rs::device_fingerprint` 使用 SHA-256；实现显示应保留 32 字节摘要对应的完整 64 个十六进制字符，允许分组换行，复制的是完整规范值。图片中的示例摘要不能作为测试向量。

认证始终绑定目标设备。本机接入用户名／密码与出站保存凭据分开管理；密码默认隐藏，错误定位到字段并保留用户名。记住凭据需要明确选择，保存与移除均说明关联范围，不能顺便删除设备或历史。

## 文件、终端、本机与其他工具

- 文件传输：当前来源、目标路径、选中项和动作方向同时可见。桌面双面板是必要的任务布局；移动端采用本机／远端单列切换。上传、下载名称与当前选择一致；覆盖确认列出受影响文件，不靠含糊的“确定”。传输进度仅显示真实已知值，未知时展示处理中。
- 终端：保留自然深色背景，明确目标和连接状态。手机辅助键贴近系统键盘；隐藏键盘时按需收起。危险命令不由界面代替用户输入。
- 本机：展示可用地址、接入状态与当前控制方；断开单个连接与停止整体共享分开。停止共享若影响现有会话，先说明影响。缺少接收权限只影响相关能力，不阻断设备浏览或出站连接。
- Android 接收权限按实际请求逐项引导；不将 Android 的屏幕／输入授权流程直接套到 iOS。摄像头、声音、文件系统范围等入口由真实平台能力控制，不支持时解释原因。
- 摄像头：当前设备、画面和停止动作明确；聊天：属于当前连接的设备沟通，不引入账号、联系人和云消息系统。端口转发仅针对原有工具能力，监听范围与停止入口应清楚。

## 视觉与组件规范

| 项目 | 基准 |
| --- | --- |
| 页面背景 | `#F8F5F0` 瓷白 |
| 主要文字／主按钮 | `#332B3B` 深茄紫 |
| 选中／轻强调底 | `#DDD7EE` 浅丁香 |
| 次要文字 | 建议 `#716B78`，最终按实际背景检查对比度 |
| 功能图标 | 一套圆角线性图标，24 逻辑像素网格，约 1.5–2 逻辑像素笔画；不混用实心、表情与不同粗细 |
| 布局间距 | 4／8 基础节奏，常用 16／24／32；移动左右边距约 20 |
| 正文／标题 | 移动正文约 16，桌面正文 14–16；任务标题约 26–32；跟随系统字体与字号 |
| 点击区域 | 移动至少 48 × 48；桌面主按钮约 38–44 高；图标视觉尺寸与实际点击区分开 |
| 圆角 | 表单与内容面 12–20，主要按钮可采用胶囊；不把每行都包成多层卡片 |
| 状态 | 文字＋图标；绿色表示成功或可用，红色用于停止／错误，颜色不作为唯一依据 |

现有 Flutter 图标可按这套规范选择并统一；实现时优先复用一套现有图标能力。Logo 的彩色、单色、反白和小尺寸需从同一矢量母版导出，不逐页重画。栅格生成稿的个别字色或笔画偏差以以上规范为准。

布局需验证小窗口、长设备名、大字号、中文／英文、屏幕阅读器与键盘焦点。正文对比度以至少 4.5:1、必要控件以至少 3:1 为验收目标；这些是后续实现的验收要求，本稿未声称通过运行时无障碍测试。

## 交付范围与实现顺序

图片覆盖核心业务页面、身份与失败状态，以及独立窗口拆合和远控工具栏隐藏状态；不是所有系统弹窗、菜单组合或深浅主题状态的穷举。D25 和 M11 分别补充桌面与移动横屏的隐藏状态，一页一图，不把多个页面拼成一张。

建议按顺序落地：① 颜色、文字、Logo 与图标基础；② 设备发现、详情、添加、认证和失败恢复；③ 独立会话窗口／标签迁移与远控悬浮工具栏；④ 文件、终端、摄像头、聊天及本机接入；⑤ 移动输入、横竖屏、系统权限与大字号验证。先做出可运行的窗口和状态，再检验静态图中未体现的交互细节。

43 张图片记录设计目标。确认方案后已开始修改真实 Flutter 应用及生产图标，当前落地范围、缩放验证和剩余工作见 [Flutter 实施记录](IMPLEMENTATION.md)；图片目录本身不代表所有页面已完成实现。
