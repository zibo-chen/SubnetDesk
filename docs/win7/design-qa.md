# Sciter / Flutter 界面对齐检查

final result: blocked

当前是候选实现，不是完整界面一致性验收。原有根目录 `design-qa.md` 保留不动。

## 证据与范围

- 源界面：`assets/screenshots/device-discovery.png`、`assets/screenshots/lan-settings.png`，均为 2112 × 1454。
- 实现截图：`docs/win7/screenshots/home.png`、`docs/win7/screenshots/lan-login.png`，均为 2120 × 1520。
- 实现使用真实 TIScript Sciter 引擎，在 macOS arm64 运行；后端为独立临时 harness 的模拟数据，不修改真实账号、凭据或网络配置。
- 实现窗口 1060 × 760 logical pixels、Retina 2×；源截图没有可验证的 logical viewport / DPI 元数据。
- 同一张临时对照图中查看了源与实现，分别缩放到不超过 780 × 590，保持比例。存在窗口高度、语言、排序、收藏状态及测试数据差异，因此不作像素级一致性结论。
- 源 LAN 设置与实现 LAN 登录属于不同流程，不能把这两张截图当作同状态对比。LAN 设置虽经过原生交互检查，最终截图仍待补录。

## Findings

- [P1] 完整页面覆盖尚未完成。
  远程工具栏、文件传输和连接管理器仍是旧 Sciter 页面，只继承共用主题与弹窗样式；Flutter 的浮动工具栏、页面布局和全部操作项尚未逐项迁移。
  修复：建立各页功能清单，按当前 Flutter 的同状态截图实现并验收。
- [P1] 最新修复后的身份选择交互待复测。
  打开原生下拉框曾触发引擎代码 0xB8，旧绑定直接 transmute 到 Rust 枚举，导致进程中止。
  修复：行为事件码改为透明整数类型，未知原因保持整数；真实引擎冒烟测试已覆盖 0xB8 事件传递并通过。
  剩余验证：Mac 已锁屏，无法完成修复后的下拉框点击和截图检查。
- [P2] 字体与界面密度仍需同 viewport 校准。
  首页的侧栏、本机卡片、三列设备卡片和蓝色主操作已采用 Flutter 的结构。实现中的设备卡片、平台图块及部分正文仍比源截图显得更高、更宽松，不能声称完全一致。
  修复：使用相同窗口、语言和设备数据对齐字体大小、卡片高度、标题间距及本机卡片密度；Windows 上复查 Segoe UI 字体和 DPI。
- [P2] 最终深色主题与认证弹窗证据缺失。
  已调整深色导航文字、select 文字及状态颜色；锁屏前的检查发现这些问题，但修复后的最终截图尚未采集。
  修复：解锁后补录深色设置、LAN 设置、身份选择及设备信任弹窗。
